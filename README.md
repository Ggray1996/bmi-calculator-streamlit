# BMI Calculator

An interactive BMI calculator built with Python and Streamlit. The app allows users to calculate their Body Mass Index using either metric or imperial measurements.

## Live App

**[Open the BMI Calculator](https://ggray1996-bmi-calculator.streamlit.app/)**

## Features

- Choose between metric and imperial measurements
- Enter weight in kilograms or pounds
- Enter height in centimeters or feet and inches
- Validate inputs before performing the calculation (checks values are not <= 0)
- Calculate BMI and display it to one decimal place
- Classify the result into a BMI category
- Display result in color based on categorty
- Reset all inputs using the reset button
